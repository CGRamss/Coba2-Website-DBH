# Detroit: Become Human — Fan Showcase

A fan-made, immersive showcase website inspired by the visual language of Detroit: Become Human.

## Sections
- Home / hero
- Synopsis / story overview
- Characters: Connor, Kara, Markus
- Story / branching narrative
- DPD case files
- Detroit 2038 timeline
- CyberLife archive
- Visual gallery
- Download / official store links

## Run
Open `index.html` in a modern browser.

## Notes
- This is a fan-made showcase, not an official Quantic Dream website.
- The Download section links to official storefronts; it does not distribute game files.
- Some visual assets are included locally in `img/`.
